# The denoiser's weights

`rt_hdr_alb_nrm.tza` is Intel Open Image Denoise's trained network for
HDR ray-traced colour with albedo and normal guides, as packaged by
oidn-web (https://github.com/pissang/oidn-web, MIT, weights under
`weights/`; sha256
e586ef2ff48d7fbb7611986405220ed8fc5c13ca79bfc40be4dc742fbf959e1a).
Open Image Denoise and its weights are Apache License 2.0, Copyright
Intel Corporation (https://github.com/RenderKit/oidn). The studio
serves the file itself so the photo's denoiser loads nothing from a
third party.
